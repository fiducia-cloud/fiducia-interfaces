# Contract provenance

This directory contains machine-readable, reviewed provenance for independently authored contract authorities and their publication snapshots.

The manifests are evidence and release gates, not a third source of payload or transport definitions. Do not copy TypeSpec or JSON Schema definitions into this directory. Update a manifest only when the referenced immutable commits/blobs or discrepancy evidence changes, then run the local and remote checks documented in `docs/commercial-intake-peer-sources.md`.
